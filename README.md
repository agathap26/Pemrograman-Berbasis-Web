  Pemrograman Berbasis Web (STSI4209)

Repository ini berisi source code Tugas 1, Tugas 2, dan Tugas 3 mata kuliah Pemrograman Berbasis Web (STSI4209) Universitas Terbuka.

Tugas 1_Aplikasi SITTA Universitas Terbuka

Folder: sitta-praktik

Membuat aplikasi web menggunakan HTML, CSS, dan JavaScript. Fitur aplikasi meliputi halaman login, dashboard, pengelolaan stok bahan ajar, dan tracking.

Tugas 2_Aplikasi Web Menggunakan Vue.js

Folder: tugas2-vue-ut

Mengembangkan aplikasi web menggunakan Vue.js untuk pengelolaan data bahan ajar, stok, dan tracking.

Tugas 3_Pengembangan Aplikasi Berbasis Komponen

Folder: tugas3-vue-ut

Mengembangkan aplikasi berbasis Vue.js dengan struktur komponen yang lebih terorganisasi, menggunakan data JSON, komponen JavaScript, dan template HTML.
